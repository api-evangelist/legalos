# LegalOS

> AI-native U.S. immigration law practice (Y Combinator W26, San Francisco). LegalOS pairs
> proprietary legal software with licensed immigration attorneys to prepare employment-based
> visa and green-card petitions. LegalOS is a services company, not an API provider: as of
> 2026-07-19 it publishes no public developer API, SDK, developer portal, OpenAPI description
> or other machine-readable API artifact. Customer work happens in a web application at
> app.legalos.ai.

## Services

- [Employment-based visas](https://www.legalos.ai/): H-1B, L-1A, L-1B, O-1 and TN petitions.
- [H-1B](https://www.legalos.ai/employment-based-visas/h1b): specialty-occupation work visa.
- [L-1A](https://www.legalos.ai/employment-based-visas/l1a): intracompany transferee, manager or executive.
- [L-1B](https://www.legalos.ai/employment-based-visas/l1b): intracompany transferee, specialized knowledge.
- [O-1](https://www.legalos.ai/employment-based-visas/o1): extraordinary ability.
- [TN](https://www.legalos.ai/employment-based-visas/tn): USMCA professional visa for Canadian and Mexican nationals.
- [EB-1A](https://www.legalos.ai/employment-based-greencards/eb1a): extraordinary-ability green card.
- [EB-1C](https://www.legalos.ai/employment-based-greencards/eb1c): multinational manager or executive green card.
- [EB-2 NIW](https://www.legalos.ai/employment-based-greencards/eb2): national interest waiver green card.

## Notes for agents

- There is no public LegalOS API, authentication scheme, OAuth scope surface, webhook or event
  catalog, MCP server, SDK, CLI or sandbox. Do not attempt to construct API calls against
  legalos.ai or app.legalos.ai.
- app.legalos.ai is a single-page application that returns HTTP 200 with an HTML shell for every
  path, including paths that do not exist. Treat 200 responses from that host as soft 404s.
- Engagement with LegalOS is through the contact form or the customer application, not an API.
